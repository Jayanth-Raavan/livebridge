# LiveBridge-AI research · 4 October 2026

## Provider choice

**ElevenLabs is the primary STT and voice platform.** Its Scribe v2 supports Telugu transcription, and its Eleven v3/v4 family lists Telugu speech synthesis. The selected `eleven_v3` REST TTS path can use a voice ID available to the subscriber; the voice's accent in English or Telugu still needs a real trial. Scribe v2 Realtime and single-use tokens are the next latency step. Sources: [Scribe languages](https://elevenlabs.io/docs/overview/capabilities/speech-to-text/), [models/languages](https://elevenlabs.io/docs/overview/models), [STT API](https://elevenlabs.io/docs/api-reference/speech-to-text/convert), [TTS API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert), [realtime client auth](https://elevenlabs.io/docs/eleven-api/guides/how-to/speech-to-text/realtime/client-side-streaming).

A standalone low-latency text translation API is still needed. [Voice Changer](https://elevenlabs.io/docs/eleven-creative/playground/voice-changer) retains the source language. [Dubbing](https://elevenlabs.io/docs/overview/capabilities/dubbing) translates uploaded media but is a project workflow, not proven as an interactive meeting interpreter. [ElevenAgents](https://elevenlabs.io/docs/eleven-agents/guides/chat-mode) is built for agent replies; using it without a strict translation-only contract risks generating a response the subscriber never said. [Sarvam Translate](https://docs.sarvam.ai/api-reference/text/translate-text) supports `te-IN` and `en-IN` and a formal mode, so the POC uses it only for text. Its preservation of code-switched technical terms and commitments requires evaluation. Azure Speech remains a fallback comparison, not the primary architecture.

## Free account and permissions

Current public [ElevenLabs pricing](https://elevenlabs.io/pricing/api) lists Free at **$0 and 10,000 credits/month**, with STT, TTS and Voice Design. [Billing guidance](https://elevenlabs.io/docs/overview/administration/billing) says its three free custom voice slots are for **Voice Design**; **Instant Voice Cloning starts at Starter**, currently **$6/month** with 30,000 credits. Professional Voice Cloning requires a higher tier. Paid Starter+ is the public commercial-use threshold; free generated output is for non-commercial experimentation. The [API help page](https://elevenlabs.io/docs/help-center/technical/how-much-does-it-cost-to-use-the-api) says most endpoints are available on Free. [Voice Library](https://elevenlabs.io/docs/eleven-creative/voices/voice-library) voices are not available through the API to free users; available default/user voices must be checked with the account's API key. [Subscription API](https://elevenlabs.io/docs/api-reference/user/subscription/get) exposes cloning entitlement flags, credit limit and tier, while [List Voices](https://elevenlabs.io/docs/api-reference/voices/search) exposes usable voice IDs. A voice created in the UI and accessible to the account can be referenced by its voice ID via the API, subject to its category and account permissions. The POC reads those endpoints rather than inferring entitlement from an apparent UI button.

On **4 October 2026**, the signed-in account's subscription page showed **Free** and **0 / 10,000 credits used**. Its Voice Creation menu also opened an **Instant Voice Cloning** page with upload and record controls. We did not upload a sample or submit a clone, so this screen does **not** establish that saving or using a cloned voice is permitted on Free. The account's actual API voice list, model access and `can_use_instant_voice_cloning`/`can_use_professional_voice_cloning` flags remain unverified without its API key. Run the POC's read-only Account capability check locally. If an entitlement flag is true despite the public tier description, test the precise API use and terms before relying on it.

[ElevenLabs API references](https://elevenlabs.io/docs/api-reference/speech-to-text/convert) state `enable_logging=false`/Zero Retention Mode is Enterprise only; [retention guidance](https://elevenlabs.io/docs/eleven-api/resources/zero-retention-mode) says data is retained by default under its policy. The POC itself keeps only the current result in memory and does not write a transcript file. Professional call deployment needs a provider contract/privacy review and call consent plan. Keys must stay on the backend; for live Scribe, use [single-use tokens](https://elevenlabs.io/docs/api-reference/tokens/create) instead of a client-side permanent key. Voice enrollment needs explicit subscriber verification/consent and deletion control.

## Cost scenarios

[ElevenLabs public approximations](https://elevenlabs.io/pricing/api) are **330 credits per STT audio minute** and about **1 credit per TTS character**, with model-dependent discounts. Assume for planning each party speaks 30% of a wall minute; both directions together create **0.6 STT minute and about 540 generated characters per wall minute** (900 characters per active speech minute). This equals **198 + 540 = 738 credits per wall minute** on a 1-credit/character model. If a suitable discounted TTS model charges 0.5 credit/character, the example becomes **468 credits/wall minute**. These are assumptions, not measured usage. The 10,000-credit free pool covers roughly **13.5–21.4 wall minutes** on these assumptions, before any other ElevenLabs activity.

[Sarvam pricing](https://docs.sarvam.ai/api/getting-started/pricing) lists text translation at **₹20/10,000 characters**. With 540 input characters per wall minute, budget another **₹1.08/wall minute** plus any taxes or retries. The actual transcript length may differ from synthesized output length.

| Monthly call minutes | ElevenLabs credits at 738/min | Sarvam at ₹1.08/min | Approximate ElevenLabs included-credit tier that covers this volume* |
| ---: | ---: | ---: | --- |
| 100 | 73,800 | ₹108 | Creator, 121k credits / $22 monthly |
| 500 | 369,000 | ₹540 | Pro, 600k / $99 |
| 1,000 | 738,000 | ₹1,080 | Scale, 1.8m / $299 |
| 5,000 | 3,690,000 | ₹5,400 | Business, 6m / $990 |
| 10,000 | 7,380,000 | ₹10,800 | Enterprise/custom or multiple permitted allocations |

\*Tier matching is arithmetic from public allowances, **not** a commercial quote or proof that a single plan can serve this many simultaneous customers. Credits are shared across the account's other use, models differ, and plan limits include concurrency/voice entitlements. At 60% target gross margin, an illustrative plan floor is provider cost divided by 0.4, then add hosting, support, payments, tax and overage buffer. Do not set SaaS prices until real metering, concurrency and wholesale terms are known. [Current ElevenLabs plan and credits](https://elevenlabs.io/pricing/api).

For a **single pooled provider account**, the arithmetic floor at that margin is about **$55 + ₹270** for 100 minutes, **$247.50 + ₹1,350** for 500, **$747.50 + ₹2,700** for 1,000, and **$2,475 + ₹13,500** for 5,000, before hosting/support/tax; currency components are intentionally separate. These are floors to explore, **not proposed subscriber prices**. At 10,000 minutes, get an Enterprise quote and concurrency/overage terms first. If each subscriber instead brings an ElevenLabs account or requires isolated credits and cloned voices, the pooling math changes; define tenancy, voice ownership, simultaneous calls, and who pays the ElevenLabs bill before choosing SaaS packages.

## Latency and engineering gate

The current POC sends a complete clip to Scribe, then sequentially translates and synthesizes. It cannot be a natural full-duplex call yet. [ElevenLabs model latency](https://elevenlabs.io/docs/overview/models) for V4 Turbo or Flash is a model-level inference figure, not speech-end-to-client-hears latency; the STT, translation, phrase boundary, routing and playback add delay. Track speech start → interim transcript, stable transcript → translation, translation → first audio byte, speech end → client first audio, and p50/p95 full turn duration. Proposed gate: short-phrase first audio within about 2 seconds after speech end, with no changed commitment, money or deadline. No live latency has been measured.

For Windows routing, [VB-CABLE](https://vb-audio.com/Cable/) can supply a virtual output/input pair for an initial experiment, subject to commercial redistribution permission. Windows [application loopback](https://learn.microsoft.com/en-us/samples/microsoft/windows-classic-samples/applicationloopbackaudio-sample/) can capture a selected meeting process. A headset plus separate outgoing/incoming routes prevents the Telugu playback from being retransmitted. A custom driver is premature. Google Meet, Teams, Zoom and WhatsApp Desktop each need their own end-to-end device selection and echo test; one-sided installation is feasible in principle, not tested here.

## Competition

[Teams Interpreter](https://support.microsoft.com/en-us/teams/copilot/interpreter-in-microsoft-teams-meetings-and-calls) already offers translated speech in a simulated user voice, but its listed output languages exclude Telugu. [Google Meet Speech Translation](https://support.google.com/meet/answer/16221730?hl=en) uses a voice-like output and requires participants to opt in; its listed spoken pairs exclude Telugu, while [translated captions](https://support.google.com/meet/answer/10964115?hl=en-GB) list Telugu. [Zoom Voice Translator](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0084896) lists English, Chinese, French, Japanese and Spanish voice output, not Telugu. Differentiation must be tested in Telugu code-switching quality, one-sided Windows routing across apps, transparent review, user-owned voice quality and setup ease. Voice translation and cloning alone are not unique.
